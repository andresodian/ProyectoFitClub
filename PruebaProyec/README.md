# PruebaProyec

Carpeta de trabajo para preparar el examen práctico de FitClub.

Alcance acotado a **2 entidades** del proyecto completo:

- **Socio** (entidad padre)
- **Membresia** (entidad dependiente, relación 1:N Socio → Membresías — la misma que ya cubre el Bloque G del mapa conceptual)

Esta carpeta se usa como espacio único para:

- El código reducido de estas dos entidades (siguiendo la estructura por módulo: `domain/`, `application/`, `infrastructure/adapter/in/web/` + `dto/`, según los PDFs del profe subidos el 10-sep).
- Las pruebas con Postman (colección y requests).
- Cualquier otro material de apoyo relacionado con el examen.
